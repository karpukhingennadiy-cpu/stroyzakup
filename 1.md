# Бизнес-процесс (для контекста)

2. DeepSeek распознаёт позиции

6. Конкурентный лист с лучшим предложением
7. Протокол PDF

# Правила работы
- Все изменения через @github: ветка `feature/backend-review`, PR в `dev`
- Commit-формат: `type(scope): description` (например: `fix(quotes): fix N+1 in competitive_sheet`)
- Следуй PEP8, используй type hints
- НЕ ломай существующие 78 тестов. Если тест падает — зафиксируй, не удаляй.
- НЕ меняй LLM-промпты в apps/emails/prompts.py без явной необходимости.
  Если изменение нужно — опиши зачем в отчёте, не применяй.
- НЕ добавляй новые pip-пакеты без обоснования. Если нужен пакет — укажи зачем.
- При изменении моделей — создавай миграцию: `python manage.py makemigrations`
- Используй полный контекст (1M токенов), проект большой.
